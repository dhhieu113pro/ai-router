# AIRouter 100% Coverage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Raise merged product line coverage for AIRouter from the normalized 85.25% baseline to 100.00% while keeping all package, container, and live OpenCode checks green.

**Architecture:** Coverage is measured from the four Cobertura reports emitted by the test projects. The CI merger must normalize source paths by assembly so the same production file is counted once. Coverage closure is test-first: add behavior tests for uncovered branches and only change production code when a test exposes an actual behavior/design issue; do not exclude reachable product code merely to inflate the metric.

**Tech Stack:** .NET 10, xUnit, coverlet.collector 10.0.1, Cobertura XML, GitHub Actions, ASP.NET Core TestHost, EF Core SQLite.

**Spec:** `docs/superpowers/specs/2026-09-05-two-package-release-design.md`

## Global Constraints

- Public NuGet surface remains exactly `AIRouter.Core` and `AIRouter.AspNetCore`.
- `AIRouter.Core` remains ASP.NET/SQLite/server independent.
- SQLite remains server-internal and non-packable.
- Fresh standalone server stores seed `opencode-free/mimo-v2.5-free` with no API key; existing stores are never overwritten.
- Existing live OpenCode smoke, package smoke, container health, trusted-publish contract, and multi-arch release behavior remain intact.
- Coverage target is 100.00% merged **product line coverage**; do not exclude ordinary reachable production code.
